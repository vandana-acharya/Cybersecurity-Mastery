# Lesson 1: How a Computer Works

## Definition

A computer is a machine that accepts input, processes it according to instructions, stores data, and produces output.

## Four Basic Functions

1. Input
2. Processing
3. Storage
4. Output

## Components

### CPU
Executes instructions.

### RAM
Temporary memory used by running programs.

### SSD/HDD
Permanent storage for files and applications.

### Operating System
Manages hardware resources and provides services for applications.

## Example

Opening `notepad.exe`:

1. User double-clicks `notepad.exe`.
2. Windows locates the executable on the SSD.
3. The program is loaded into RAM.
4. The CPU executes its instructions.
5. Windows creates a new process.
6. The Notepad window appears.

## Cybersecurity Relevance

Understanding how applications start helps explain process creation, telemetry, and how EDR solutions monitor system activity.
